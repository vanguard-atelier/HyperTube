## 🚀 The Lore (Attempt 3: Redemption)
- **Attempt 1 (`Soytube`):** Handed a barebones player with zero extractor. 💀
- **Attempt 2 (`HyperDeck`):** Accidentally built an embedded web wrapper. ✌🏻💀
- **Attempt 3 (`HyperTube`):** The real deal. Forked from LibreTube's rock-solid native ExoPlayer engine, refactored with HyperOS aesthetics, zero bloat, and custom branding.

---

## ✨ Features

- 🎨 **HyperOS Color Palette:** Signature HyperOS electric blue accents (`#007AFE`) and deep titanium dark mode (`#0D0D11`).
- 🎬 **Native ExoPlayer:** Raw hardware-accelerated playback with Media3.
- 📐 **Tablet & Large Screen Optimized:** Full support for dual-pane tablet navigation (Redmi Pad Pro).
- 🚫 **No Ads & SponsorBlock:** Built-in ad blocking and SponsorBlock integration.
- 📱 **Pip & Background Playback:** Native Android Picture-in-Picture and background audio streaming.
- 🔒 **Privacy-First:** Powered by the Piped API backend — no Google Services or account tracking required.

---

## 🛠️ Build & Install

Automated debug APKs are compiled on every commit via GitHub Actions.

1. Go to the **[Actions](https://github.com/vanguard-atelier/HyperTube/actions)** tab.
2. Select the latest workflow run.
3. Download the APK artifact and install it directly on your device.
